# Armed and Dangerous'27 Content Plan

The content plan for Armed and Dangerous'27 (Video, Social media, Writers). Jul 17–20, 2027, Jos.

A static site with no build step.

- `index.html`: page shell.
- `assets/data.js`: every session, team, piece and reference link.
- `assets/app.js`: name picker, duties, session tabs and piece cards.
- `assets/styles.css`: design.

## Run locally

```bash
npx serve .
```

## Deploy on Vercel

Import the repository and keep the defaults (framework preset "Other", no build command, output directory `.`).
